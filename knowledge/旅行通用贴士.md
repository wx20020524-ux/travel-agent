# 旅行通用贴士知识库

## 一、行前准备清单

### 1.1 证件类

- 身份证：国内旅行必备，酒店入住高铁飞机全部需要
- 护照/签证：出境游提前办理，签证提前1-3个月
- 驾驶证：自驾租车必备，部分地区需翻译件
- 学生证/老年证/军官证：景点门票半价优惠
- 儿童：户口本/出生证明

### 1.2 电子设备

- 手机 + 充电器 + 充电宝（飞机不超过100Wh可随身带
- 相机 + 存储卡 + 电池
- 转换插头：国外（英标、欧标、美标、澳标）
- 耳机：降噪耳机高铁飞机必备

### 1.3 衣物类（按季节打包）

- 原则：洋葱式穿搭，方便增减
- 必备：舒适的运动鞋/徒步鞋
- 泳衣：酒店温泉游泳
- 防晒帽/墨镜/防晒霜

### 1.4 洗护日用

- 洗漱包：牙刷牙膏（部分酒店不提供
- 女生护肤化妆品分装瓶
- 个人常备药品：
  - 感冒药（泰诺、999感冒灵
  - 肠胃药（蒙脱石散、黄连素、益生菌
  - 创可贴
  - 晕车药
  - 过敏药（氯雷他定）
  - 退烧止痛药（布洛芬）

### 1.5 其他必带

- 雨伞/一次性雨衣（山区多变
- 保温杯/水杯
- 纸巾/湿巾
- 塑料袋若干（收纳/脏衣
- 便携垃圾袋
- 头灯/手电筒（山区
- 小锁（青旅 locker

## 二、预算控制技巧

### 2.1 交通省钱

1. 机票：
   - 提前30-45天预订
   - 周二周三相对便宜
   - 红眼航班更低价
   - 航司会员日促销
   - 往返票比单程有时更划算
2. 火车：
   - 高铁/动车提前15天放票
   - 夕发朝至卧铺省一晚住宿
3. 市内：
   - 公交地铁为主，打车为辅
   - 远途拼车/顺风车

### 2.2 住宿省钱

- 提前预订：提前1-2个月Booking/Agoda比价
- 灵活日期：周末节假日价格可上浮30-100%
- 位置：地铁沿线上盖物业价格低
- 青旅：女生间女生，多人间多人间
- 民宿：整套多人出行

### 2.3 餐饮省钱

- 避开景区吃，去本地居民区吃
- 大众点评/美团优惠券
- 早餐便利店解决
- 超市买水零食比景区便宜

### 2.4 门票省钱

- 学生证半价/老年证免票政策
- 联票套餐/年卡
- 官方公众号提前预订早鸟票
- 免费开放日

## 三、安全注意事项

### 3.1 人身安全

1. 夜间避免单独前往偏僻地区
2. 机场车站人多拥挤处看管好手机钱包
3. 不乘坐黑车，正规出租车
4. 青旅 locker 贵重物品寄存前台
5. 告知家人朋友每日行程
6. 护照身份证拍照备份，复印件分开存放

### 3.2 财务安全

- 现金分开放，贴身+行李
- 信用卡不要离开视线
- 公共 Wi-Fi 不要进行网银操作
- 购买旅游保险：航班延误险、意外险

### 3.3 健康安全

- 不喝自来水，喝瓶装水
- 海鲜新鲜卫生
- 随身携带常用药
- 高原地区提前防高反：不要剧烈运动
- 防晒：SPF50+ PA++++ 防晒霜

## 四、摄影出片技巧

1. 黄金时段：日出后1小时，日落前1小时
2. 避开人群：早到景点1小时开门前
3. 构图：三分法、对称、引导线、前景
4. 服装：和背景色对比
5. 夜景三脚架长曝光

## 五、独自旅行贴士

1. 轻装简行李可登机行李随身登机口
2. 跟家人报平安每日行程
3. 存当地大使馆/报警电话
4. 保持手机保持电量在线
5. 信任直觉不对劲就离开危险环境

## 六、亲子游贴士

1. 行程安排不要太满，每天1-2个核心景点
2. 带推车/背带
3. 常备零食水/玩具
4. 选含儿童设施多的酒店
5. 准备常用药：退烧药、退热贴、腹泻药

## 七、老人出行贴士

1. 行程节奏慢，少换乘少步行
2. 选景点之间交通打车/包车
3. 酒店带常用药慢性病药带足量
4. 体检证明随身
5. 保暖防滑鞋防滑
